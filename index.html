About the data

Prices come from the public PlayStation Store website data for the selected region, fetched by this site’s own server (browsers cannot read the Store directly). “Popular” means a game ranks high in the Store’s best-seller order among current deals, or belongs to a well-known franchise. “Best deal” scores deep discounts on high-priced, popular games highest. Prices change quickly, so check the Store page before you buy.
